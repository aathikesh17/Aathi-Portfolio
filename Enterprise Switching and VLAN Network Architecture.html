Enterprise Switching and VLAN Network Architecture

Enterprise network design implementing VLANs, multilayer switching, trunking, and inter-VLAN routing.

Objective : Design and simulate an enterprise network that implements VLAN segmentation, inter-VLAN communication, and automated IP address management using DHCP services.

Technologies Used : Cisco Packet Tracer, VLAN, Inter-VLAN Routing, Multilayer Switching, DHCP, DHCP Relay, ROAS, DTP, Static Routing.

Network Configuration

  • Configured VLAN segmentation for multiple departments and implemented SVI (Switch Virtual Interface) on a multilayer switch for inter-VLAN routing.
  • Implemented DHCP Server and DHCP Relay Agent to dynamically assign IP addresses across different VLAN networks.
  • Configured ROAS (Router on a Stick), DTP trunking, and Access Ports to enable VLAN communication between switches and routers.
  • Implemented Static Routing and HTTP services to enable network connectivity and web service access within the enterprise network.

Outcomes : Successfully built a scalable enterprise network demonstrating practical switching concepts, VLAN segmentation, DHCP automation, and inter-VLAN communication using Cisco Packet Tracer.
